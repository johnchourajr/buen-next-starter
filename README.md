# Buen Starter

A Next.js starter template built with TypeScript, Tailwind CSS, and Motion.

## Prerequisites

- Node.js 20.9 or later
- pnpm (recommended package manager)

## Installation

Install dependencies using pnpm:

```bash
pnpm install
```

## Development

Start the development server:

```bash
pnpm dev
```

The app will be available at [http://localhost:3010](http://localhost:3010).

## Available Scripts

- `pnpm dev` - Start the development server
- `pnpm build` - Build the application for production
- `pnpm start` - Start the production server
- `pnpm lint` - Run ESLint
- `pnpm format` - Format code with Prettier

## Package Manager

This project uses [pnpm](https://pnpm.io/) as the package manager. If you need to install pnpm:

```bash
npm install -g pnpm
```

Or using Homebrew on macOS:

```bash
brew install pnpm
```
